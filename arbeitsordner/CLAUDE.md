# Arbeitsordner Schlomo und Adelheid

Diese Datei lesen auch alle Prüfer mit. Sie enthält deshalb keine Falldaten und keine fachlichen Anweisungen.

- Falldaten kommen nur über die Werkzeuge der lokalen Engine (`mcp__engine__...`). Die Engine gibt nur
  anonymisierte, von der Psychologin freigegebene Daten heraus.
- In diesem Ordner gibt es keinen Zugriff auf Dateien, keine Shell und kein Web. Das ist Absicht, kein Fehler.
- Bitte nie nach Namen, Geburtsdaten, Adressen oder anderen Klardaten fragen und keine Dokumente anfordern.
  Fehlt etwas, als Lücke benennen.
- Arbeitsabläufe stehen in den Skills dieses Ordners.
